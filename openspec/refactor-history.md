# Refactor History

This file preserves completed numbered OpenSpec refactors — internal code-hygiene changes with **no** user-visible behavior change.

Only completed refactors keep permanent `refactor-XXX` numbers. Live unnumbered candidates are tracked in [`refactor-backlog.md`](./refactor-backlog.md), and a candidate receives the lowest unused refactor number only when promoted into implementation. Cancelled or deferred refactor candidates do not reserve refactor numbers.

| refactor-001 | `delete-row-confirm` | outdoor/tracks-edit | Extracted `useDeleteRowConfirm<T>({ deleteAction, title, getDescription, deletedMsg, notFoundMsg })` into `lib/use-delete-row-confirm.ts` and wired it into `tracks-admin-panel.tsx`, `hikes-admin-panel.tsx`, and `photos-admin-panel.tsx`, shrinking each by ~35 lines. The hook returns a spreadable `confirmDialogProps` object rather than rendering `ConfirmDialog` itself, so the dialog stays a presentation concern of the panel. Six values parameterize (row generic, action, title, description builder, two toasts); `confirmLabel`, `confirmVariant`, and the post-delete `router.refresh()` are hardcoded. Two behaviors deliberately preserved and flagged in the design: `setTarget(null)` + `router.refresh()` run **unconditionally**, so a failed delete still closes the dialog and refetches; and the hikes panel's `"Trip deleted"` / `"Trip not found"` toasts stay out of sync with its `"Delete hike?"` dialog title, because that is how it already read. Highest-confidence lift from research-001. No behavior change; `skip_specs: true`. Happy path verified in the browser in all three panels on 2026-10-21 — the not-found branch, cancel path, double-submit guard, and a local `npm run build` are deferred to [`openspec/backlog.md`](./backlog.md) as `outdoor-admin-delete-row-confirm-manual-qa`. Artifacts: [`openspec/changes/archive/2026-10-21-refactor-001-delete-row-confirm/`](./changes/archive/2026-10-21-refactor-001-delete-row-confirm/). |
| refactor-002 | `sortable-header` | admin/tables | Extracted `SortableHeader` into `components/common/sortable-header.tsx` and wired it into **19 sortable column headers across 10 admin table files** (categories, files, hikes, links, md-docs, photos, posts, tracks-admin-columns, video-channels, videos), collapsing 10 distinct inline shapes into one component; `ArrowUpDown` and three now-unused `Button` imports removed as fallout. Two behaviors were deliberately preserved and documented. First, `className` is load-bearing: **5 of the 19 sites** pin their header to `w-36` / `w-28 justify-start`, so dropping the prop would have collapsed those headers and changed column widths — a visible change that would have forfeited this change's place in the `refactor-XXX` pool. Second, the click expression `column.toggleSorting(column.getIsSorted() === "asc")` is copied verbatim, which keeps the sort cycle **two-state, not three-state** (unsorted → asc → desc → asc). Passing an explicit boolean sets `hasManualValue` in TanStack's `RowSorting`, which skips the only branch that can remove a sort, so the column is re-assigned instead of cleared and never returns to the original order. That is pre-existing behavior at all 19 sites, not something this change introduced — making it three-state is a visible change filed as `admin-sortable-header-third-click-no-unsorted`, and a direction-aware icon as `admin-sortable-header-direction-aware-icon`, both at P0. An earlier draft of `design.md` asserted the opposite about the argument-less `toggleSorting()` form; it was corrected after the browser check and the TanStack source were read. Browser verification by the user on 2026-10-21: sorting behaves identically across all ten tables, the five width-pinned headers hold their columns, and `npm run build` passed. The same pass surfaced an unrelated pre-existing defect filed as `admin-videos-table-horizontal-overflow`. Net effect `+40 / −161` across 11 files. This refactor is what makes both P0 follow-ups one-line changes instead of 19 hand-edits. No behavior change; `skip_specs: true`. Artifacts: [`openspec/changes/archive/2026-10-21-refactor-002-sortable-header/`](./changes/archive/2026-10-21-refactor-002-sortable-header/). |
